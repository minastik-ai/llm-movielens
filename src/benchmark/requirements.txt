# messages.create(), so on 1.x the generator cannot reproduce the sampling the
# paper states. torch / sentence-transformers move the EMBEDDINGS, which are the
# paper's features, so a drift there moves every number for anyone who
# regenerates rather than downloading.

                              # in the genome scores and changes the rendered prompts (tested: 2.3.3 to 3.0.2)
scipy>=1.10.0,<2.0

# Sentence transformers (for BERT title baseline)
sentence-transformers>=2.2.0,<6.0

# Evaluation & analysis
